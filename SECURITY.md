# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We take security seriously. If you discover a security vulnerability within this project, please follow these steps:

1. **Do NOT** open a public issue on GitHub.
2. Email our security team at `security@example.com` (Replace with actual contact).
3. Include full details of the vulnerability:
   - Description of the issue.
   - Steps to reproduce.
   - Potential impact.
   - Any proof-of-concept code.

## Discovery & Disclosure Timeline
- **Response**: We will acknowledge your report within 48 hours.
- **Triage**: We will verify the vulnerability and determine its severity within 5 days.
- **Fix**: A patch will be prepared and tested.
- **Release**: A security update will be released as soon as possible.
- **Disclosure**: Public disclosure will occur only after the fix has been applied to the production branch.

## Safe Harbor
We support safe harbor for security researchers. If you follow this policy and act in good faith, we will not pursue legal action against you.
