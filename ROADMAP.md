# Roadmap

## Short-term Goals (Q2 2026)
- [ ] **Email Notifications**: Send email alerts for loan approvals and due date reminders.
- [ ] **Search & Filter**: Advanced search for books by author, category, or rating.
- [ ] **User Avatar**: Allow users to upload profile pictures.

## Medium-term Goals (Q3 2026)
- [ ] **E-Book Support**: Reader interface for PDF/ePub files.
- [ ] **Payment Integration**: Fine management for overdue books using Stripe/PayPal.
- [ ] **API Token System**: Full REST API for mobile app integration.

## Long-term Vision (2027+)
- [ ] **Mobile App**: Native React Native application.
- [ ] **AI Recommendations**: Recommend books based on user history.
- [ ] **Multi-Library Support**: SaaS model for multiple libraries.
